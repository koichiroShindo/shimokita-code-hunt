# Shimokita Code Hunt（仮）

下北沢を訪れる外国人観光客向けのサイト。駅のQRコードから開き、好みを選ぶとお店が3軒表示される。3軒を回って、店内のQRコードを読んで集める。

## 流れ
1. 下北沢駅の壁に貼ったQRコードからサイトを開く
2. 好みを選ぶ（古着・レコード・ギター/楽器・純喫茶・隠れ家カフェ・スイーツ・カレー・隠れ家バー・ライブハウス/レコードバー・小劇場・ミニシアター/お笑い・古本屋・小さなギャラリー・アンティーク/手作り雑貨の14種類）
3. 好みに合うお店が3軒表示される（Googleマップへのリンクつき）。2〜3種類選ぶと、それぞれの種類から1軒ずつ選ぶ
4. お店でQRコードを読むと、位置情報でお店の近く（80m以内）にいるかを確かめて記録する
5. 3軒そろったら、別の好みでもう3軒探せる（前に見つけたお店は後回しになる）

画面は英語・中国語・韓国語・日本語に切り替えられる。

トップページに下北沢駅まわりの地図（OpenStreetMap）を載せている。3軒の一覧には、駅から3軒を順に回る道順をGoogleマップで開くボタンがある。

## ファイル
- `index.html`：サイト本体（画面はすべて `app.js` が組み立てる）
- `qr.html`：駅用・各店用のQRコードを印刷するページ（公開後にこのページを開いて印刷する）
- `data/config.js`：サービス名、距離の判定などの設定
- `data/stores.js`：お店の一覧。今は下北沢の実在のお店を候補として、種類ごとに5軒以上（計67軒）入れている。観光客がほとんど来ない、路地裏・2階以上・地下・建物の一室にある個人店だけを選び、チェーン店や有名な施設は入れていない（QRコードを置く許可はまだとっていない）
- `images/street/`：トップページの写真（企画スライドの写真から切り出したもの）
- `images/shops/`：お店の写真を入れる場所
- `i18n.js`：画面の文言（4言語）
- `style.css`：見た目
- `vendor/qrcode.js`：QRコードを作る部品（qrcode-generator 1.4.4、MITライセンス）

## お店を足す
`data/stores.js` に書く。位置（lat, lng）はGoogleマップでお店を右クリックすると出る。足したら `qr.html` を開いて、そのお店のQRコードを印刷する。

## お店の写真を入れる
1. 写真を長辺1600px程度・1MB以下に縮小し、撮影日時や位置情報（EXIF）を消す
2. `images/shops/` に `お店のid.jpg`（例：`bear-pond-espresso.jpg`）の名前で入れる
3. `data/stores.js` のそのお店に `photo: "bear-pond-espresso.jpg", credit: "出典",` を足す（credit は画面には出さず、掲載の許可をとった相手の記録として残す）

お店の写真は、お店に掲載の許可をとってから入れる。

## 今の試作で決まっていないこと
- **お店の許可**：お店の中にQRコードを置くので、1軒ずつ許可をとる
- **位置（lat, lng）が空**：今はすべて null で、位置を確かめずに記録している。お店ごとに入れれば、80m以内にいるかを確かめるようになる
- **住所の確認**：Webの紹介記事から拾った住所なので、移転・閉店していないかをお店に確かめる。flocci・Best Sound Record・Latte・SWEET TWIST・Kappa ism・SPICE KITCHEN MOONA・素今歩は番地が分かっていない。モナリザコーヒーは「北沢2-34-8付近」（地図のリンクは店名で探す）
- **トップページの写真**：企画スライドの写真を使っている。自分たちで撮ったものでなければ差し替える
- **QRコードのURLは調べれば分かる**：お店に行かずにURLを開いても位置情報で弾くが、位置情報をごまかす方法はある
