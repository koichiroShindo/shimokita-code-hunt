# Shimokita Code Hunt（仮）

下北沢を訪れる外国人観光客向けのサイト。駅のQRコードから開き、好みを選ぶとお店が3軒表示される。3軒を回って、店内のQRコードを読んで集める。

## 流れ
1. 下北沢駅の壁に貼ったQRコードからサイトを開く
2. 好みを選ぶ（古着・レコード・カフェ・ライブハウス・本屋・ホビー・雑貨・食べ物）
3. 好みに合うお店が3軒表示される（Googleマップへのリンクつき）
4. お店でQRコードを読むと、位置情報でお店の近く（80m以内）にいるかを確かめて記録する
5. 3軒そろったら、別の好みでもう3軒探せる（前に見つけたお店は後回しになる）

画面は英語・中国語・韓国語・日本語に切り替えられる。

## ファイル
- `index.html`：サイト本体（画面はすべて `app.js` が組み立てる）
- `qr.html`：駅用・各店用のQRコードを印刷するページ（公開後にこのページを開いて印刷する）
- `data/config.js`：サービス名、距離の判定などの設定
- `data/stores.js`：お店の一覧。今は下北沢の実在のお店を候補として10軒入れている（QRコードを置く許可はまだとっていない）
- `i18n.js`：画面の文言（4言語）
- `style.css`：見た目
- `vendor/qrcode.js`：QRコードを作る部品（qrcode-generator 1.4.4、MITライセンス）

## お店を足す
`data/stores.js` に書く。位置（lat, lng）はGoogleマップでお店を右クリックすると出る。足したら `qr.html` を開いて、そのお店のQRコードを印刷する。

## 今の試作で決まっていないこと
- **お店の許可**：お店の中にQRコードを置くので、1軒ずつ許可をとる
- **位置（lat, lng）が空**：今はすべて null で、位置を確かめずに記録している。お店ごとに入れれば、80m以内にいるかを確かめるようになる
- **住所の確認**：Webの紹介記事から拾った住所なので、移転していないかをお店に確かめる。disk union は番地が分かっていない
- **QRコードのURLは調べれば分かる**：お店に行かずにURLを開いても位置情報で弾くが、位置情報をごまかす方法はある
