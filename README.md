# Shimokita Backstreets

下北沢を訪れる外国人観光客向けのサイト。駅に貼ったQRコードから開き、好きなスタイルを選ぶと、そのスタイルに入るお店がすべて表示される。載せているのは、ビルの2階より上・地下・路地の奥にある小さな個人店。

## 流れ
1. 下北沢駅に貼ったQRコードからサイトを開く
2. トップではお店の写真が5秒ごとに切り替わる（矢印・点・停止ボタンでも操作できる）
3. スタイルを選ぶ。ファッション（古着）は7つの系統（アメカジ・カジュアル / Y2K・ストリート / スポーツ・ゲームシャツ / ヨーロッパ・クラシック / モード・デザイナーズ / グラフィック・キャラクターT / リメイク・一点物）、そのほかはレコード・ギター/楽器・純喫茶・隠れ家カフェ・スイーツ・カレー・隠れ家バー・ライブハウス/レコードバー・古本屋・小さなギャラリー・アンティーク/手作り雑貨
4. 選んだスタイルのお店が、写真・紹介文・住所・Googleマップと公式SNSへのリンクつきで並ぶ。10軒以下なら、駅から順に回る道順をGoogleマップで開くボタンも出る

画面は英語・中国語・韓国語・日本語に切り替えられる。選んだ言語とスタイルは、そのブラウザの中にだけ保存する（位置情報は使わない）。

## ファイル
- `index.html`：サイト本体（画面はすべて `app.js` が組み立てる）
- `qr.html`：駅に貼るQRコードを印刷するページ（公開後にこのページを開いて印刷する）
- `data/config.js`：サイト名、運営者と連絡先
- `data/stores.js`：お店の一覧（58軒、うち写真ありが57軒）
- `images/shops/`：お店の写真
- `images/street/`：写真のないスタイルを選んだときに使う下北沢の写真
- `i18n.js`：画面の文言（4言語）
- `style.css`：見た目
- `vendor/qrcode.js`：QRコードを作る部品（qrcode-generator 1.4.4、MITライセンス）

## お店を足す
`data/stores.js` に書く（書き方はファイルの先頭にある）。

## お店の写真を入れる
1. 写真を長辺1600px程度・1MB以下に縮小し、撮影日時や位置情報（EXIF）を消す
2. `images/shops/` に `お店のid.jpg`（例：`bear-pond-espresso.jpg`）の名前で入れる
3. `data/stores.js` のそのお店に `photo: "bear-pond-espresso.jpg",` を足す。横幅が800px未満の写真は、トップの大きな写真にするとぼやけるので `slide: false,` も足す

お店の写真は、お店に掲載の許可をとってから入れる。

## ファイルを変えたら
`style.css`・`app.js`・`i18n.js`・`data/*.js` を変えたら、`index.html` の `?v=数字` を1つ増やす（古いファイルが残って表示が崩れるのを防ぐため）。日付は使わない。

## 決まっていないこと
- **写真がないお店**：武蔵屋画廊
- **住所の確認**：Webの紹介記事から拾った住所なので、移転・閉店していないかをときどき確かめる
